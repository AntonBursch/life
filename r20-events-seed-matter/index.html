R20 — Events seed matter

First Phase-B composition. No new operator. Barkley spirals (R7) emit rising-edge events through threshold_event (R18). Each event deposits V into an autonomous Gray-Scott chemistry (R4) running in the stable-spots regime (f=0.030, k=0.062). The wave only writes; the chemistry runs by itself. Turn the wave off and the pattern keeps going — and even grows.

the claim

Discrete events from one substrate can deposit persistent matter in another substrate.

The wave never feeds the chemistry. It only fires. Each rising edge is a single bit — 1 here, 0 there — emitted by threshold_event at the moment a cell crosses the threshold. The handler reads that bit and writes V into the chemical substrate. From the chemistry's perspective, the wave is invisible: it just gets occasional seeded spots and runs its own Pearson-regime dynamics on them. Stop the wave and the spots keep replicating.

try this

  1. Default. Let it run ~30 seconds. You should see spots dotting the path of the spiral. Some will replicate.
  2. Turn the wave off. Click Wave: ON (it becomes OFF). Panel 1 stops changing, panel 2 goes dark. Panel 3 keeps evolving. New spots appear from splitting, not from new events.
  3. Reset chemistry, keep the wave. The pattern rebuilds from the next wave passage. Run-to-run reproducibility lives in the spiral.
  4. Lower the threshold. More cells fire on each wave passage. The grid fills faster — but the isolation gate keeps spots spaced.
  5. Compare with R13. R13 gates Gray-Scott feed via excitable_gate — continuous bias. If you stopped the wave there, chemistry would die because the feed-field bias would die with it. R20's chemistry is autonomous. The wave is creative, not modulatory.
