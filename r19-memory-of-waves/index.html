R19 — Memory of waves

Tenth composition. Phase A closer. New operator integrate_field: the kit's "integrate" primitive — a per-cell leaky integrator. Same Barkley substrate as R7 and R18; instead of detecting events, we accumulate u. With leak = 0 the operator is a pure dose meter: total u-exposure per cell. With leak > 0 it is a low-pass filter — the field settles at <u>/leak, a time-averaged map of excitable activity.

the claim

R18 added the discretise operator: continuous in, symbolic out. R19 adds its dual: continuous in, continuous out, but with memory. integrate_field advances dy/dt = input − leak · y by one Euler step. With leak = 0, the operator integrates forever — a dose meter, an odometer, a fluence map. With leak > 0, it forgets exponentially — a low-pass filter with time constant τ = 1/leak, exactly the "leaky integrate" half of a leaky-integrate-and-fire neuron.

The composition is a single substrate paired with two integrators on the same operator. Panel 2 forgets; panel 3 doesn't. Both are honest views of the wave — one as recent average, one as cumulative history. Together they show what "integrate" means as a primitive on the kit: memory length is a parameter, not a structural choice.

try this

  1. Default (leak = 0.10, τ = 10). Watch panel 2 settle. After a few τ the leaky map converges to a steady spatial pattern: the time-averaged activity. The "observed" and "predicted" rows in the readout should converge.
  2. Leak = 2 (τ = 0.5). Short memory. Panel 2 almost mirrors panel 1 — the integrator is fast enough to track u. Steady state is small: <u>/leak ≈ 0.1.
  3. Leak = 0.01 (τ = 100). Long memory. Panel 2 grows for a long time before saturating; the steady state <u>/leak is large (~20). The map is a smooth average over many spiral rotations.
  4. Panel 3 grows forever. The dose-meter panel just keeps brightening. Compare its rate to mean(u): the panel value increases by <u>·t. That is what a pure integrator does.
  5. Reset memory. Wipes both integrators but leaves the tissue alone. You can watch them re-converge from zero on the same wave.
  6. Kick centre. A transient bump appears immediately in u, slowly in y, and permanently (as a slight increment) in the dose. Three different time scales, one input.

what to look for

  • Steady state matches theory. The readout's "<y> predicted" is <u> ÷ leak. After a few τ, the observed mean should be within a few percent. CLI run confirmed it: <u>=0.21, predicted 2.12, observed 2.20.
  • Dose grows linearly. Pure accumulator. After 1500 steps max dose was 17.6; after 3000 steps it was 34.1 — exactly 2× for 2× time. That is the signature of an integrator with zero leak.
  • Memory length, not architecture. The same operator runs in both panels with different leak. Long-term vs short-term memory is a slider, not a rewire.
  • R18 vs R19. R18 made discrete events out of continuous waves. R19 makes a continuous record of those waves. The pair is the kit's bridge in both directions between fields and processes with memory.

why this rung matters — Phase A complete

R19 closes Phase A. The kit now has eight operators in six categories: read-by-threshold, read-by-peak, read-by-magnitude, differentiate (scalar + vector), transport, discretise, integrate. With these eight primitives the substrates can be composed in essentially any direction we want: react, diffuse, sync, gate, route, carry, fire, remember. Phase B will start composing them into specific behaviours we want — modules, not rungs.

Operator alphabet (8 ops, 6 categories): excitable_gate, phase_to_scalar_field, bulk_gate, gradient_magnitude, gradient_field, advect_by, threshold_event, integrate_field.

Math + code: flow::Barkley2D, flow::integrate_field (new — leaky-Euler integrator on a field).
