R28′ — Bistable communication

Phase E, second rung. R27′ established that a real bistable reaction can hold "wall vs. not-wall" without a comparator. R28′ asks: does the wall need to be built where it ends up? Same chemistry as R27′, plus a transport term. The spiral's footprint on the left commits cells to X = 3; advection carries that X mass rightward; downstream cells get a bolus of inflow that pushes their local concentration past the X = 2 separatrix; from there the Schlögl rate law does the rest. No latch anywhere, no comparator anywhere — communication is mass-action plus transport.

The composition. Same alphabet as R27′, plus the existing advect_by: 

Barkley → react_field(X, schlögl + drive) → advect_by(X, v) → modulate_parameter → ε

No new operator in this rung. Pure composition over an honest substrate.

the claim

Communication is reactant transport plus local bistability. No latches, no advected labels. The spiral runs on the left; X is produced there; the velocity field carries it right; downstream cells cross their own separatrix and self-commit. The right-half walls are built by chemistry the spiral delivered, not by a flag it set.

CLI verified at default settings (v = 2.5 rightward, drive 4.0, u_θ 0.8): by t = 30, X_high_R ≈ 0.23 with the spiral still confined to its own footprint on the left. By t = 200 the spiral has self-extinguished (advected X has raised ε globally enough to kill the wave) and X_high_R is still climbing, reaching 0.45 by t = 400 — driven entirely by reactant inflow plus local rate law, with no wave anywhere on the grid.

try this

  1. Default. Watch X build on the left, then leak rightward as a slowly broadening front. The third panel shows ε following along.
  2. Kill wave. Spiral disappears. X does not. The advection keeps pushing whatever X is already there rightward; downstream commitments continue to occur until the source is depleted.
  3. Set velocity = 0. The channel closes. X still grows under the spiral but stops migrating; the right half stays at X = 1.
  4. Negative velocity. Flip the channel: now X migrates leftward and pools at the periodic wrap-around. Same mechanism, opposite direction. The velocity field is the wire.
  5. Drive below 2. Spiral can't commit anyone locally; nothing gets put on the wire. Bistability without forcing is invisible.
  6. Reset chemistry. Slams X back to 1 everywhere. The only external knob — there is no path back through the substrate itself.

what changed vs. R28

R28 chain: latch_field → advect_by(label) → latch_field → ε. The advected field was a Schmitt output.

R28′ chain: react_field(X) → advect_by(X) → ε. The advected field is the reactant itself. No latches in either layer.

No new operator in this rung — same composition as R28, applied to an honest substrate. R28′ inherits react_field from R27′ and reuses the existing advect_by. The alphabet stays put; the substrate gets honest.
