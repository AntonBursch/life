# Notes — the road to the floor of life

Running notes from Anton's conversation with Copilot, in the order we
walked them. Each note has the math, followed by the same idea in code,
because Anton reads code more fluently than equation notation.

These are study notes, not a textbook. They're meant to be re-read.
They're meant to keep getting longer.

## Conventions

- **Math first**, in standard notation (KaTeX). Then the same idea in
  JavaScript so we can read what each symbol does.
- Code is meant to be readable, not optimised. No build step, no deps.
- When a note implies an experiment we should actually run, it's
  flagged at the bottom under "experiment seed."
- If a note's claim turns out to be wrong as we go, the note gets
  edited in place with a dated correction. We don't pretend we never
  said the wrong thing.
