the claim

An excitable wave with handedness produces coherent transport of inert matter even with no memory in the pipeline.

R22 needed a memory: the past was compiled into geometry, and that geometry pulled matter around. R23 strips the memory out. There is nothing but the current wave and the current payload. Each wavefront passage gives the payload a kick; in a symmetric system the kicks cancel. A spiral is not symmetric. Its arms always sweep the same way. The kicks accumulate. The wave moves the cargo without ever remembering it had.

try this

  1. Default. Payload starts in the upper-left. It first jostles in place, then starts orbiting the spiral as the arms reach further out.
  2. α = 0. No transport. Sanity check that the drift comes from the wave, not from any background flow or initial conditions.
  3. Drop several payloads. Click in different quadrants. Each blob drifts in the same rotational sense — chirality is global, not local.
  4. Compare with R22. R22 needed hundreds of tissue-time units to build the memory map before the dye drifted. R23 starts transporting immediately — the wave does not wait to be remembered.
  5. Strong α. The payload smears along each wavefront before the next one arrives. Motion is wavefront-aligned, not net.
