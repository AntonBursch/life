R25 — Homeostasis

Phase C, second rung. First negative-feedback control loop. R24 closed the loop spatially (local memory sets local excitability). R25 closes it globally and scalar: total Barkley activity drives a single ε setpoint that pulls the system to a target activity level. A leaky integrator controller — ε_offset ← (1−leak·dt)·ε_offset + k·(activity − target)·dt — on a non-linear plant (the spiral). Same parametrise category as R24, no new operators.

Toggle the controller off: the spiral runs at its natural ~0.21 activity and the trace flatlines well above target. Toggle back on: ε rises until activity is dragged down to the dashed target line. Kick the medium: activity spikes, then the controller answers and pulls it back. That is the minimum signature of homeostasis — a return-to-setpoint after a perturbation.

the claim

The system has a setpoint. Whatever you do to it, the controller drags activity back to the target.

R24 closed the loop in a way that always pushed the system away from its natural state — more activity made more scar, full stop. R25 is the first rung that regulates. The error has a sign; the controller pushes up or down to cancel it. A disturbance (the kick button) becomes a transient, not a permanent shift. The free-running natural activity (~0.21) is no longer where the system lives — it lives wherever you tell it to. Two-state controller (offset + tissue), one knob (target). This is what a thermostat does. It is also what a beating heart does, what blood-pH does, what every closed biological control loop does. From here, every further rung will be about composing these loops, not inventing them.

try this

  1. Default (target=0.15, k=1, controller on). After warmup, ε rises to ~0.03–0.04 and activity settles around 0.15. The two trace lines move in opposite directions — more ε, less activity, in gentle balance.
  2. Toggle controller off. ε drops to base; activity climbs to its natural ~0.21. Open-loop steady state.
  3. Kick under regulation. Activity spikes; ε climbs in response; activity is dragged back down within ~10–30 tissue-time units. The return-to-setpoint is the homeostasis.
  4. Change target to 0.18. Wave relaxes back toward its natural state, ε falls. Same controller, different setpoint, different living point.
  5. Drop target to 0.10. Right at the edge — the controller can push activity low, but if ε goes past the wave-extinction threshold the spiral dies and cannot revive. Low-target homeostasis is fragile; high-target is easy. Real biology has the same asymmetry.
  6. Gain = 0 with controller on. Same as controller off — the leaky integrator has nothing pushing it, so ε_offset stays at 0.
