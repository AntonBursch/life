R24 — Scar tissue

Phase C opener. The first closed loop. Past activity does not just shape what the dye sees (R22) or where it is carried (R23) — it shapes what the tissue itself will do next. integrate_field builds a memory of u; the new operator modulate_parameter turns that memory into a per-cell excitable parameter ε(x) = ε₀ + gain · memory; Barkley reads that field via step_with_eps_field. The wave writes its own substrate.

Panel 3 is the scar map — brighter cells take longer to recover from excitation, the wave drags or stalls there. With moderate gain, the system reaches a homeostatic equilibrium: the spiral keeps firing but at reduced territory, regulated by its own trail. With high gain, the wave kills itself. With zero gain, the loop is broken and you have R7 again.

the claim

The substrate's own dynamics depend on its own history. The wave is not running on a fixed stage; it is rewriting the stage as it goes.

Until this rung every rung was feedforward. Substrate produced a field, operators read it, the substrate didn't notice. R24 closes the loop: the integral of past activity becomes a parameter that the substrate itself reads on its next step. With moderate gain the system regulates — it cannot run hot for long because hot regions become slow regions. That is the minimum signature of cybernetics: a system whose own output is one of its inputs. Three operators (one of them new), one substrate hook (step_with_eps_field), and the wave starts shaping itself.

try this

  1. Default (gain 0.02). Wave settles into a steady reduced state — excited fraction stabilises around half of its R7 baseline. The scar map fills in a halo around the spiral; the wave keeps spinning but inside a region of its own choosing.
  2. Gain = 0. Loop opened. Memory still builds but never feeds back to ε. This is R7 / R19 — the wave runs forever at full power. Direct A/B with default proves the cybernetic effect is in the loop, not in the substrate.
  3. High gain (0.05+). The wave lays scar faster than it can travel and strangles itself. excited frac collapses to zero.
  4. Heal scar. Resets memory and ε to baseline without disturbing u. The wave that was wedged in a shrinking region suddenly has the whole grid available again.
  5. Long memory (leak = 0.02, τ = 50). Memory accumulates without forgetting; even low gain eventually kills the wave. Memory length matters as much as feedback strength.
  6. Short memory (leak = 1.0, τ = 1). Memory barely persists; ε flickers but does not build a permanent scar. Loop is closed but doesn't bite.
