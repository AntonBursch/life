the claim

The present motion of matter can depend on what happened in the past — not via any current state of an active substrate, but via the integrated trace the past left behind.

R7 produced a wave. R17 transported dye by a velocity field. R19 turned a time-series into a spatial memory. Until this rung the three were separate stories. Here the memory becomes a force. The dye does not "know" there is a wave; it never samples u. It samples ∇memory — a quantity that did not exist a hundred steps ago. Past activity has been compiled into a present geometry, and matter now obeys that geometry. It is the first rung where time turns into force.

try this

  1. Default. The dye starts as a blob to the right of the spiral. Centroid drifts left over a few hundred tissue-time units.
  2. α = 0. Memory still builds, but the dye is decoupled from it. Blob stays put (small numerical diffusion only). Sanity check that motion comes from memory, not from anywhere else.
  3. Short memory (leak = 1.0, τ = 1). Memory tracks the instantaneous wave too closely — its gradient flickers with each wavefront. Dye gets stirred locally but doesn't drift anywhere coherent.
  4. Long memory (leak = 0.02, τ = 50). Memory builds up a slow, smooth bowl around the spiral's territory. Dye drifts cleanly toward the centre.
  5. Reset memory mid-flight. The dye stops drifting almost immediately. Velocity is grad(memory); with no memory there is no velocity. The wave passing now has no effect on the dye until memory rebuilds. "Forgetting" turns the dye loose.
  6. Drop dye blob in different spots. Each blob drifts toward the memory hotspot from its own position. The same geometry pulls every blob; the geometry was authored by the wave's history.
