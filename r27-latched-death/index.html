R27 — Latched death

Phase D opener. R26 walls only persisted because the wave kept writing them; kill the wave and they dissolve. R27 introduces the first operator with its own persistent state: latch_field, a per-cell Schmitt trigger. When memory crosses set_threshold the cell flips into the wall state; with reset_threshold = 0 it stays walled forever, regardless of what happens to the wave that put it there. Press Kill wave and watch: the spiral disappears, the walls do not.

The third panel is the latched wall state, not the live memory. It only flips ON when memory crosses set and only flips OFF when memory drops below reset. With reset at 0 the latch is a one-way trap: once a cell is walled, no input can release it. Kill wave zeros u and v; the walls do not move.

the claim

Some things are not erasable. Every operator until now has been a function of its current inputs alone. latch_field is the first operator whose output depends on its inputs and its own persistent state. That single change unlocks irreversibility: the system can carry the fact of having been somewhere even after every other trace of that visit has decayed away.

In R26 wave and structure were inseparable — kill the process and the structure goes with it. In R27 wave and structure are decoupled: the spiral is the builder, the latched wall_state is the artifact. The artifact outlives its maker. That is the minimum signature of biological structure — you can die and your bones remain.

CLI verified at set 1.0, reset 0.0, kill_eps 0.05, leak 0.5: latched walls plateau at ~28% of the grid while the spiral runs steady at excited ≈ 0.17. Wave killed at step 12000 (tissue time 240): wall_frac stays at 0.276 indefinitely. The R26-equivalent control (no latch, memory drives ε directly) shows walls at ~14% during the run, decaying to 0 within ~120 t.u. of the kill. Same alphabet plus one new operator, qualitatively new behaviour.

try this

  1. Default. Watch walls accumulate in the spiral's most-visited regions. They plateau (the spiral has a bounded footprint) but never erode.
  2. Kill wave. Zeros u and v. The wave vanishes; memory decays toward zero within ~10 t.u.; the wall_state field does not change at all. The structure is fully decoupled from the process now that the latch holds it.
  3. Reseed spiral after killing the wave. The fresh spiral has to live inside the pre-existing latched walls, which the new wave did not build. History from the previous wave is still steering this one.
  4. Heal walls. Clears memory and the latch. Explicit reset — the only way to undo a one-way latch is from outside the substrate.
  5. Raise reset threshold above 0. Re-introduces erasability. With reset = 0.2 and leak = 0.5, walls fade within ~10 t.u. of the wave dying. Tune reset to set the system's "forgetting rate".
  6. Raise set threshold to 2.0. Memory rarely reaches that level. Walls barely form. The latch is still there, just very selective about what counts as commitment.
