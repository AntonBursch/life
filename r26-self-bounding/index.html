R26 — Self-bounding

Phase C, third rung. R24 closed the loop with a smooth map (memory dims the tissue everywhere). R25 closed it with a global setpoint (one knob, the whole grid). R26 closes it with a sharp threshold: bulk_gate turns memory into a binary wall mask. Where memory crosses the cutoff, ε snaps from base to kill_eps and that cell is no longer excitable. The wave does not equilibrate with itself — it carves a domain and lives inside it. No new operators, just sharpness.

the claim

History becomes geometry. R24 made the tissue dimmer where the wave had been; R26 makes it absent. The accessible part of the medium is no longer a global property — it is a self-built shape, and the wave lives strictly inside it.

CLI verified at sharpness 0.05, threshold 0.3, kill_eps 0.10, leak 0.5: walls stabilise at ~63% of the grid while excited_fraction holds at 0.21–0.26 indefinitely — the same activity level as a free R7 spiral, but on roughly a third of the available area. With sharpness 0.5 (same threshold, same memory, same kill_eps) the smooth gate dissolves the partition and the wave dies. The qualitative difference is in shape of the map, not in any new physics. Same alphabet, new mode.

That is what an alphabet is supposed to do — give you new behaviour by composition. This is the third consecutive Phase-C rung where one chain (integrate → map → parametrise) produces a qualitatively different system depending only on which map you put in the middle. R24 affine, R25 leaky integrator on a scalar setpoint, R26 sharp sigmoid. Three different theories of "what the past does to the future", same wiring.

try this

  1. Default. Watch the wall map fill in the wake of the spiral. After ~50 tissue-time units the walls reach steady state at ~63%, the spiral keeps spinning forever in the remaining third.
  2. Crank sharpness to 1.0. Walls soften into a smooth halo — and the wave dies within ~30 t.u. The smooth map dims the whole neighbourhood; the sharp map dims only where it must. Same threshold, opposite outcome.
  3. Lower threshold to 0.1. Walls form faster than the spiral can recruit fresh tissue. Strangulation.
  4. Raise threshold to 0.8. Walls never form (memory equilibrates below 0.5 at this leak). Free R7 spiral.
  5. Reseed spiral with walls intact. The fresh spiral must fit inside the pre-existing no-go region. It will deform around the walls rather than rebuilding the same shape from scratch — the memory survived the wave reset.
  6. Heal walls. Resets memory and ε without touching the wave. Watch the spiral immediately expand to fill the now-fresh grid, then re-carve.
