R21 — Sensor and alarm

Second Phase-B composition. No new operator. Chains two Phase-A primitives plus a latch: integrate_field (R19) smooths the raw Barkley activator u into a leaky time-average; threshold_event (R18) fires on the rising edge of the averaged signal; an OR-latch keeps the alarm bit set once raised. Same threshold, same wave, but the integrator turns "instantly excitable" into "persistently excited".

Read in order. Panel 1: the wave that does the sensing. Panel 2: its leaky integral — how much activity each cell has accumulated, with time constant τ = 1/leak. Panel 3: the latched alarm map — cells where ⟨u⟩ has, at some point, crossed the trip threshold. The alarm only grows. Try kicking once and watching: a single transient bump barely lifts panel 2 and never reaches panel 3. Only sustained or repeated excitation latches.

the claim

Transient excitation should not trip the alarm; sustained excitation should.

R18 thresholds the raw signal u and fires on every wave passage — wherever the wave goes, an event appears, immediately. R21 thresholds the leaky integral of u. A cell has to keep being excited for long enough that its running average climbs past the trip level. Once it does, an OR-latch holds the bit. That is the architecture of an industrial sensor: smooth the signal, trip on the smoothed value, latch the trip. Two operators and a single bit of state per cell.

try this

  1. Default. τ = 5, threshold = 0.3. The alarm map fills in gradually — not on the first wave passage but after several. Watch panel 2's ⟨u⟩ build up where the spiral revisits often.
  2. Reset sensor (not alarm). Wipes ⟨u⟩ but keeps the latched bits. Useful to confirm the alarm is *truly* a latch: panel 3 does not clear.
  3. Reset alarm (not sensor). Wipes the latch but keeps the integrator state. The cells currently above threshold trip again on their next rising edge.
  4. Short memory (leak = 2, τ = 0.5). The integrator can barely accumulate. ⟨u⟩ tracks u closely. Behaviour collapses toward R18 — every visited cell trips quickly.
  5. Long memory (leak = 0.05, τ = 20). Very slow accumulation. The alarm map fills in much more slowly; many cells that the wave grazes briefly never trip.
  6. Higher threshold. Only the hottest patches — typically the spiral core neighbourhood — ever latch. The alarm becomes a "this region got hit hard" map.
  7. Kick on a blank field. Reset tissue, then kick. A single bump shows up in panel 2 as a small bright patch that decays. With threshold ≥ 0.3 it never latches. Same operator chain, but transient ≠ sustained.
